# NeuroLog (fork)

**Fork** of NeuroLog — open-source daily tracking app for children with special educational needs: categorized event logging (emotions, behavior, nutrition), trend charts and role-based collaboration between parents, teachers and clinicians.

**Stack:** Next.js · TypeScript · Supabase
